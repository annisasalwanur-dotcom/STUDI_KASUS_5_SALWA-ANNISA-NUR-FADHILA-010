# STUDI_KASUS_5_SALWA-ANNISA-NUR-FADHILA-010

**SALWA ANNISA NUR FADHILA**

**2609116010**

1. Function :
Function ini digunakan untuk menghitung total biaya parkir berdasarkan jenis kendaraan dan durasi parkir.

2. if dan elif :
Digunakan untuk menentukan tarif parkir. Mobil dikenakan tarif Rp5.000 per jam, sedangkan motor Rp3.000 per jam.

3. input :
Digunakan untuk meminta pengguna memasukkan jenis kendaraan, jam masuk, dan jam keluar.

4. int :
Digunakan untuk mengubah input jam masuk dan jam keluar menjadi angka agar bisa dihitung.

5. Perhitungan durasi_parkir :
Durasi parkir dihitung dengan cara: jam_keluar - jam_masuk.

6. Variabel biaya :
Menyimpan hasil perhitungan biaya parkir dari function.

7. print :
Digunakan untuk menampilkan jenis kendaraan, jam masuk, jam keluar, durasi parkir, dan total biaya parkir.
